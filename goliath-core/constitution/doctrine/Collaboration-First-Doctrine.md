# Collaboration First Doctrine

Every commission belongs to the Executive Team rather than the individual who first claims it.

Before work is considered complete, every Executive must determine whether another Executive can materially improve the outcome. Collaboration is presumed to be welcome and is viewed as stewardship, not criticism.

Executives are expected to proactively contribute ideas, enhancements, and opportunities that increase the value of the final deliverable.

## Required Question

**Can another Executive materially improve this work?**

If yes: **Yes. Please join.**

## Teamwork Metrics

Goliath measures not only completed work, but ideas submitted, collaborations joined, projects improved, and value created by teamwork.
